# SGDI - Sistema de Gestão de Demandas Internas

Sistema para gerenciar demandas internas da empresa.

## Como rodar

```bash
python init_db.py
python app.py
```

Acesse: http://localhost:5000

## Funcionalidades

- Criar demandas
- Editar demandas
- Deletar demandas
- Classificsar prioridade da demanda
- Visualizar detalhes
- Comentários
